      Before you download
      
        
      Is BLADE free, and do I need an account?
      BLADE is free and open source. You can use the website without creating an account or installing an app. The source code and command-line version are available on GitHub.
      
        
      Can I download a YouTube playlist as MP3?
      Yes. Select Audio / MP3 before starting. Each completed audio file includes metadata and a 480 × 360 YouTube thumbnail as cover art. You can save the MP3 files individually or together in a ZIP.
      
        
      Is there a playlist-size limit?
      There is no application cap on the number of playlist items, file sizes, or total download duration. Available server storage, network access, and YouTube availability determine what can finish. ZIP64 supports large archives.
      
        
      What happens to private or deleted videos?
      Known private and deleted entries are skipped before downloading. Videos that become unavailable during extraction are not retried by the extractor. The queue continues with the remaining videos.
      
        
      What if someone else is downloading?
      Playlists enter a shared first-in, first-out queue. BLADE can prepare up to two playlists at the same time while sharing its 16 parallel download workers between them. You can also run your own copy from GitHub.
      
        
      How long are my files available?
      Files expire one hour after your download finishes. They can also be removed when the server restarts, so save your ZIP or individual files promptly.
